# Luxury Dream Cars Website 🚗🔥

Welcome to the Luxury Dream Cars Website project — a modern and responsive car showcase website created using HTML and CSS and hosted on AWS S3 Static Website Hosting.
This website features some of the world's most luxurious and high-performance supercars with a premium black and red themed UI design.
---
## ✨ Features
✔ Responsive Website Design  
✔ Modern Black & Red Luxury Theme  
✔ Real High-Quality Car Images  
✔ Smooth Card Hover Effects  
✔ Clean and Attractive UI  
✔ AWS S3 Static Website Hosting  
---
## 🚘 Cars Featured
- Porsche GT4
- McLaren 720S
- Mercedes AMG GT
- Ferrari SF90

- CSS3
- AWS S3 Static Website Hosting
